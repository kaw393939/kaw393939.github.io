02 / AI tooling · Python

Everyday AI CLI

Published alpha · v0.2.2

A command-line toolkit that brings AI image, audio, and search workflows into repeatable commands.

Built
Commands for image generation and analysis, transcription, speech, audio translation, and web search.
Practice
A plugin architecture lets additional commands extend the toolkit without replacing its core interface.

Published on PyPI as an alpha. AI commands require access to the relevant provider APIs.

A guided studio where students turn a neutral T-shirt storefront into a brand and a live style guide.

Built

Practice
