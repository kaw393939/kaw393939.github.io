# Accessibility and language support

I want this site to be useful across languages, devices and ways of reading. Accessibility is part of the work, not a promise that every barrier has already been found.

## What is available

- A keyboard-accessible “Skip to content” link, visible focus indicators and semantic headings.
- Responsive pages that can be zoomed, with reduced-motion preferences respected.
- Text alternatives for photographs and illustrations.
- An optional English audio introduction with its full written transcript. Audio does not autoplay.
- A [Brazilian Portuguese introduction](/pt-br/) with language-labeled links. Most detailed guides remain in English. AI-assisted translations are identified and have not yet received independent linguistic review.

The language selector uses language names rather than flags. Choosing Portuguese opens an introduction; it does not claim to translate the page you were reading. No automatic locale redirects or third-party translation widgets are used.

## Testing and limits

The project aims toward WCAG 2.2 AA. Automated checks cover selected markup, contrast, page structure and language metadata. They are not a certification. Full assistive-technology, real-device and human usability testing remains necessary; linked project sites have separate interfaces and may have different limitations.
