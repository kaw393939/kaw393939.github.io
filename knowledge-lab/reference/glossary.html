Shared vocabulary ​

A file, a statement in that file and a decision to publish that statement are three different records. The vocabulary below lets a team discuss each one precisely.

Share on LinkedIn

LinkedIn opens a draft you can review before posting.

Look up the word at the point where you have to make a decision. Which words came from the source? Which passage can a reader find? Which worker still owns the job?

Evidence and review ​

TermMeaning here
ArtifactImmutable source or derived bytes with a cryptographic digest.
AcquisitionWhere, when and how someone obtained the material.
MentionA name or reference at a precise source location.
Entity and aliasAn entity is a stable identity. An alias is a name it uses in a particular context.
ResolutionA reviewable decision about which identity a mention refers to. It can remain unresolved.
Claim and assertionA claim is a proposition with its qualifications. An assertion records what a particular source says about it.
ProvenanceThe trail from source through processing and review to publication.
Draft or proposalA candidate change waiting for review or publication.
RevisionA published state retained so a reader can reopen the evidence cited at that point.
GraphA record of typed relationships among identities, claims and evidence.
AugmentationGenerated context linked to, and kept distinguishable from, original evidence.
NERNamed-entity recognition identifies mentions in a passage. Identity resolution is a separate decision.

Retrieval and delivery ​

TermMeaning here
Embedding spaceA vector representation defined by a model and its preprocessing rules.
BM25A lexical ranking method available through SQLite FTS5.
ANNApproximate nearest-neighbor search. Compare it with an exact reference to measure recall.
RRFReciprocal rank fusion combines positions in different ranked result lists.
Hybrid retrievalCombining available lexical, vector or graph results.
RAGRetrieval-augmented generation supplies selected evidence to a model before it answers.
SSEServer-sent events deliver incremental updates from a server to a browser.
ProjectionAn authorized view that can be rebuilt from durable records.

Jobs and releases ​

Suppose the same worker name receives an extraction job twice. Attempt 1’s lease expires. Attempt 2 has a new epoch and returns on time. The store checks the epoch and accepts the eligible result once, even if the worker resends it. Try the lease exercise.

TermMeaning here
DAGA directed acyclic graph of task dependencies.
LeaseA time-limited assignment of one task to a worker attempt.
Fencing epochAn attempt identifier that allows the store to reject an older worker’s result.
IdempotencyRepeating an accepted request leaves its durable effect unchanged.
OutboxA record committed with a change so a corresponding event can be delivered reliably.
CapabilityA versioned operation a worker implements.
ReleaseA tested software artifact with approved configuration and compatibility information.
